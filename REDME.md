# Formation Développeur Web Fullstack

## 🚀 Présentation
Bienvenue dans ce parcours d'apprentissage intensif de 6 semaines pour devenir développeur web fullstack. Ce programme couvre les fondamentaux du développement web moderne, incluant JavaScript, SQL, la Programmation Orientée Objet (POO) et la modélisation UML.

## 📋 Structure du programme
Le programme est divisé en 6 semaines thématiques, chacune construisant sur les compétences acquises précédemment:

- **Semaine 1:** Fondations (JavaScript, Classes, SQL, Fonctions)
- **Semaine 2:** Consolidation (Structures de contrôle, Méthodes et constructeurs, SQL avancé)
- **Semaine 3:** Concepts intermédiaires (Fonctions avancées, Héritage, Jointures SQL)
- **Semaine 4:** Approfondissement (Gestion des erreurs, Polymorphisme, Sous-requêtes SQL)
- **Semaine 5:** Intégration (Programmation asynchrone, Encapsulation, Conception de BDD)
- **Semaine 6:** Révision et pratique (Projets intégrateurs)

## 🎯 Objectifs d'apprentissage
- Maîtriser les fondamentaux de JavaScript
- Comprendre et appliquer les principes de la POO
- Concevoir et interroger des bases de données SQL
- Utiliser UML pour modéliser des systèmes
- Développer des applications web interactives
- Appliquer les bonnes pratiques de développement

## 💻 Comment utiliser ce repo
Chaque semaine possède son propre dossier avec un README détaillé présentant:
- Les objectifs d'apprentissage
- Le contenu journalier
- Des exercices progressifs (faciles, moyens, difficiles)
- Des ressources documentaires

## 🔍 Niveaux de difficulté
Les exercices sont classés en trois niveaux:
- **Facile:** Exercices d'introduction aux concepts
- **Moyen:** Application des concepts dans des scénarios réalistes
- **Difficile:** Défis plus complexes combinant plusieurs concepts

## 🏆 Défis couverts
- **JavaScript:** Variables, fonctions, tableaux, objets, classes, DOM, événements, asynchrone
- **SQL:** SELECT, INSERT, UPDATE, DELETE, jointures, sous-requêtes, agrégations
- **POO:** Classes, objets, héritage, polymorphisme, encapsulation, abstraction
- **UML:** Diagrammes de classes, use cases, relations
